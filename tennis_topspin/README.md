```bash
#    文件 → 首选项 → 附加开发板管理器网址，粘贴:
#    https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
#    工具 → 开发板 → 开发板管理器 → 搜索 "esp32" → 安装

# 3. 安装传感器库
#    项目 → 加载库 → 管理库 → 搜索并安装:
#    - "ICM42688" (作者 hideakitai)

# 4. 安装 Python 依赖（本项目的桌面端）
cd "/Users/zhangsanmao/claude code/tennis_topspin/desktop"
pip3 install -r requirements.txt
```

### 第 2 步：收到硬件后 —— 接线

**实验阶段用面包板，无需焊接。**

```
ESP32-S3 Mini          ICM-42688-P 模块
+-------------+        +-------------------+
| 3V3     ----|------->| VCC               |
| GND     ----|------->| GND               |
| GPIO6   ----|------->| SDA               |
| GPIO7   ----|------->| SCL               |
+-------------+        +-------------------+

ESP32-S3 Mini          TP4056 充电模块
+-------------+        +-------------------+
| 5V      ----|------->| OUT+              |
| GND     ----|------->| OUT-              |
+-------------+        | B+  ---> 锂电池正极 |
                        | B-  ---> 锂电池负极 |
                        +-------------------+
```

实物操作顺序：
1. 面包板放在桌上
2. 把 ESP32-S3 Mini 和 ICM-42688-P 模块插在面包板上
3. 用母对母杜邦线按上面表格连接（共 4 根线）
4. 电池正负极接 TP4056 的 B+ / B-
5. TP4056 的 OUT+/OUT- 接 ESP32-S3 的 5V / GND
6. 最后插上电池（不要先通电）

### 第 3 步：烧录固件

1. USB-C 数据线连接 ESP32-S3 到电脑
2. 打开 Arduino IDE
3. 打开本项目 `firmware/tennis_sensor/tennis_sensor_icm42688.ino`
4. **工具 → 开发板 → ESP32 → ESP32S3 Dev Module**
5. 工具 → 端口 → 选择出现的串口（如 `/dev/cu.usbmodemXXX`）
6. 点击 **上传（→ 箭头）**
7. 上传成功后，**工具 → 串口监视器**，波特率设为 **115200**
8. 应该看到：

```
正在初始化 ICM-42688-P...
传感器就绪 | 芯片ID: 0x47
ICM-42688-P 配置完成 (200Hz, ±16g, ±500dps)
BLE 广播已启动 | 设备名: TennisSwing
等待挥拍...
```

> 如果看到"传感器初始化失败"，检查 I2C 接线（SDA/SCL 是否接反或接触不良）。

### 第 4 步：连接电脑并挥拍

1. 打开终端，运行：

```bash
cd "/Users/zhangsanmao/claude code/tennis_topspin/desktop"
python3 main.py --ble
```

2. 看到 `BLE 已连接!` 和 `已订阅数据通知，等待挥拍...` 即成功
3. 拿起球拍（传感器绑在拍柄底部），做上旋挥拍动作
4. 每次挥拍后终端显示评分，同时弹出图表窗口
5. 按 `Ctrl+C` 退出，自动保存练习总结

### 第 5 步：固定到球拍上

实验通过后，用魔术贴绑带把传感器盒子固定在拍柄底部（靠近拍喉处）：

```
      球拍头部
        |
   ==========
   |        |
   |  拍面  |
   |        |
   ==========
        |
   ┌────────┐  ← 拍喉
   │ 传感器  │  ← 用魔术贴固定在这里（拍柄上方）
   ├────────┤
   │ 拍柄   │
   │        │
   └────────┘  ← 拍柄底部
```

> Z 轴方向：传感器平贴在拍柄上，Z 轴（垂直于传感器平面）大致指向拍面法线方向。

## 四、常见问题

**Q: 传感器没反应？**
A: 检查 I2C 接线，SDA/SCL 是否插反。串口监视器里会打印错误信息。

**Q: BLE 搜不到设备？**
A: 确认 ESP32-S3 已烧录成功（串口监视器看到"BLE 广播已启动"）。macOS 系统偏好设置 → 蓝牙中应该能看到 "TennisSwing"。

**Q: 评分一直很低？**
A: 先用几次校准。真实的挥拍数据分布可能和预置阈值有差异，后续可以调整 `scorer.py` 里的参数。

**Q: 使用 SPI 接线？**
A: 取消 `tennis_sensor_icm42688.ino` 里 `// #define USE_SPI` 的注释，接线改为 6 根线（加 MOSI、MISO、SCK、CS）。
